# Northwind-Sales-Operations-Analysis
Analyzed 830 orders and $1.27M in sales using SQL Server and Power BI. Conducted sales, product, customer, employee, and shipping analysis using advanced SQL techniques including CTEs, window functions, like CASE statements. Built a 3-page interactive Power BI dashboard to visualize key business trends and performance metrics.

All tables and data provided by: https://www.dataquest.io/projects/guided-project-a-sql-window-functions-for-northwind-traders/
